Bulk Data Import / Export v3

Odoo 202-minute walkthrough

From a messy customer file to a safe import, a dry run and an undo. Odoo's standard import stops at the first error; this one saves every good row and gives you an Excel file of the failed ones with the reason next to each.

  • Check File lists every problem in the whole file before anything is saved
  • Dry Run shows old value next to new, then runs it for real
  • Skip unchanged rows on re-imports
  • Smart column matching: "E-mail", "Town", even untitled columns
  • Undo by batch, shared mappings and expiring export links
