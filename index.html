v1Security · Contacts, HR, Banking, CRM

Data Vault Encryption

Plain in Odoo. Sealed in the database.

Field-level encryption at rest for Odoo: chosen fields and attachments are encrypted with AES-256-GCM, the same cipher governments use for TOP SECRET data, before they reach PostgreSQL, so dumps, backups and replicas only hold ciphertext. The master key stays in the server’s odoo.conf, so it protects dumps, backups and direct database access, not someone who can read the server’s files.

  • Presets for contact PII, HR personal data, IBANs and CRM leads; blind index search, raw SQL guard, audit log
  • Key rotation while Odoo runs, a key per department, read and export audit and a GDPR compliance PDF
  • Background jobs with a live progress bar and a guided setup on Odoo 20; 161 automated tests
